 # Smart Tomato Farm
IoT 기반 방울토마토 스마트팜 시스템 분석 및 설계

## 1. 프로젝트 개요
- 과목: 시스템 분석 및 설계
- 개발 대상: 방울토마토 양액재배 하우스
- 개발 목적: 재배환경 모니터링 및 자동제어
- 가상 사업 예산: 50,000,000원
- 개발 상태: 시스템 분석 및 설계 단계

## 2. 주요 기능
- 온도·습도·CO₂·일사량 모니터링
- 양액 EC·pH 및 공급량 관리
- 환기팬·급액 펌프 제어
- 재배 일지 및 수확량 관리
- 센서 이상 감지 및 알림

## 3. 기술 스택
- Frontend: React, TypeScript
- Backend: Java, Spring Boot
- Database: PostgreSQL
- IoT: ESP32, Raspberry Pi
- Communication: MQTT, WebSocket
- Deployment: Docker

※ 기술 스택은 개발 계획 기준이며 구현 완료를 의미하지 않습니다.
