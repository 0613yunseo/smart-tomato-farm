# AI Prompt History

## 사용 도구
- ChatGPT
- 활용 목적: RFP 분석, 시스템 설계 및 문서 제작

## Prompt 01. 최초 개발 계획 수립
### 입력 프롬프트
방울토마토 하우스 배양 재배 스마트팜 개발 계획서를
작성해줘. 무슨 기술 스택, 테이블 이런 방향도
같이 작성해야 됨.

### 생성 결과
- 시스템 개발 방향 수립
- 기술 스택 구성
- 데이터베이스 테이블 초안 작성

### 검토 및 수정 방향
초기 계획의 범위가 넓어 핵심 기능을 중심으로
개발 계획을 압축할 필요가 있다고 판단하였다.

## Prompt 02. 개발 계획 구체화
### 입력 프롬프트
시퀀스 다이어그램 포함해서 계획서 줄여서
함축된 시스템개발계획서 작성해줘봐.

### 생성 결과
- 주요 기능 정리
- 시퀀스 다이어그램 추가
- 개발 일정 및 테스트 계획 정리

### 이후 작업
교수님의 RFP를 반영하여 시스템 제안서,
개발 계획서, 구축 결과 및 검증 계획을 통합하였다.
